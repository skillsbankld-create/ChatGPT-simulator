# ChatGPT Simulation Lab

Interactive training replica of the ChatGPT interface (November 2026), built from a full tutorial video.

- 17 scenarios, each in three modes: Watch, Try, Test
- Practice mode: every button, menu and field works
- English / Arabic toggle, full screen (press F)
- Single file: `index.html`, no build step

Live site: enable GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
