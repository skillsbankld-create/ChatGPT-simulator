# ChatGPT Simulation Lab

Interactive training replica of the ChatGPT interface (November 2026), built from a full tutorial video.

- 20 scenarios in Watch, Try and Test, with Egyptian workplace examples in mixed Arabic and English, including 3 scored work challenges (complaint analysis, angry-customer email, safe policy summary), with decisions, branching and a 5-criterion competency score
- Learners type their own prompts; each one is checked against criteria with explanatory feedback
- Practice mode: every button, menu and field works
- English / Arabic toggle, full screen (press F)
- Single file: `index.html`, no build step
- Optional live AI through OpenAI, protected by a trainer panel, session codes and limits: see SETUP-AI.md. Without it, everything works with built-in criteria checks

Live site: enable GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
