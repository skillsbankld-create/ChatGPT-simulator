# ChatGPT Simulation (Skills Bank)

Interactive training replica of the ChatGPT interface (November 2026), for trainees who do not have ChatGPT accounts.

- **Explore:** the ChatGPT interface opens directly. Every button, menu and field works.
- **Assistant:** click any button and a card explains what it does, why it helps at work, and which plan has it. Turn on "Explain before clicking" to read first, then try. With live AI on, trainees can also ask free questions.
- **Plans:** switch between Free, Go, Plus, Pro and Business at the top and see which features open, plus a side-by-side plan comparison.
- **Feature map:** pick a feature and the simulator opens it and highlights where it is.
- **How do I…?** 17 guided how-tos in Watch and Try.
- **Challenges (optional):** 3 scored work challenges (complaint analysis, angry-customer email, safe policy summary).
- English / Arabic, full screen (press F). Single file: `index.html`, no build step.
- Optional live AI through OpenAI, protected by a trainer panel, session codes and limits: see SETUP-AI.md.

Live site: enable GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
